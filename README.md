# 大肥鱼陪你一起备考

一个**单文件、离线可用**的长期目标执行器。

把「今天要学什么」变成「今天有一只鱼要喂」。

> 在线体验：<https://lian20080520.github.io/dafeiyustudy/>
>
> 备用地址：<https://dafeiyu-study.app.workbuddy.host/?sharecode=U6I5KQ5ZHB>

---

## 它解决什么问题

自习室里的真实困境不是「不知道要学」，而是：

- 目标写在纸上，第二周就不再打开
- 番茄钟响了很多次，但没人知道这周到底推进了什么
- 计划一旦断一天，就再也没有第二天

所以这个项目只做三件事：**拆小、计到、看见**。把长期目标拆成今天能做完的一件事，把它计进去，然后用一个会饿的伙伴让你第二天想回来。

## 玩法

1. **立目标**：写下一个长期目标，比如「两个月过四级」。
2. **拆任务**：把目标拆成一条条可以打勾的小任务。
3. **开专注**：25 分钟一个番茄钟，结束自动记录，中间离开会被记下来。
4. **喂大肥鱼**：每完成一件事，它会吃饱一点、开心一点。断更会饿。
5. **看复盘**：每天一封日报，每周一次复盘，用数据告诉你节奏对不对。

## 它和普通番茄钟的区别

| | 普通番茄钟 | 大肥鱼 |
|---|---|---|
| 计时 | 有 | 有 |
| 中断记录 | 多数没有 | 有，且会被记进当日日报 |
| 目标与任务的层级 | 无 | 目标 → 任务 → 番茄钟 |
| 长期反馈 | 一个总时长数字 | 每日日报 + 每周复盘 |
| 回来的理由 | 自律 | 一只会饿的鱼 |

## 技术实现

### 单文件、零依赖

整个应用是一个 `index.html`，约 1.4 MB，**没有任何外部请求**——样式、脚本、图片、音频全部内联。

放在 U 盘里能跑，断网能跑，拷给同学双击就能跑。这也是刻意为之：面向校园场景分发，不要让人先装环境。

### 关键实现

- **内嵌音频**：背景音乐以 base64 形式内联，用 `AudioContext` 解码后循环播放。为了消除 MP3 循环接缝，做了首尾交叉淡入淡出。
- **专注背景音**：白噪声走低通滤波（1150 Hz 附近），听起来像远处的空调，不像收音机杂音。
- **立绘动画**：点亮/加油两套状态帧内联为 WebP，用 CSS 变换驱动，避免逐帧图片带来的体积和内存开销。
- **24 时段问候**：根据当前时刻切换问候语与立绘状态，凌晨和深夜是不同的话。
- **开场转场**：一个独立的小引擎，用设计工具的语言（标尺、参考线、尺寸标注、打字、钢笔锚点）把界面「搭」出来，再闪白揭示真实应用。音效全部由 Web Audio 现场合成，不占体积。
- **本地持久化**：全部数据存 `localStorage`，不上传任何服务器。清浏览器数据会清空进度。
- **减动效适配**：`prefers-reduced-motion` 开启时直接跳过开场动画，不让人卡在仪式感里。

### 深链参数

方便分享和演示：

| 参数 | 作用 |
|---|---|
| `?app=1` | 跳过开场，直接进入应用 |
| `?go=1&t=3.2` | 定格开场第 3.2 秒，用于截图 |
| `?m=theater` | 深色观影版 |

## 本地运行

```bash
git clone https://github.com/<your-name>/dafeiyu-study.git
cd dafeiyu-study
```

然后双击 `index.html`。不需要服务器、不需要 `npm install`、不需要联网。

> 想用本地服务器打开也可以：`python -m http.server 8000`，然后访问 `http://localhost:8000`。

## 浏览器支持

Chrome / Edge / Safari 近两年版本；移动端 iOS Safari 与 Android Chrome 均已适配，支持刘海屏安全区。
